# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do NOT open a public issue**
2. Email: [gersi.maja3@gmail.com] *(replace with your actual email)*
3. Include a description of the vulnerability and steps to reproduce

I will respond within 48 hours.

| Version | Supported |
|---------|-----------|

## Scope

This repository contains educational lab exercises for CCNA preparation. It does not process user data or handle authentication. The auto-grader (`index.html`) runs entirely client-side in the user's browser — no data is sent to any server.

## Best Practices for Contributors

- Do not commit credentials, API keys, or sensitive information
- Do not add external scripts or CDN links without review
- All contributions must go through a Pull Request and be approved before merging
